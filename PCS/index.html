The PCStar is a system I imagined for hobbyists and alike that would combine every single version of every system used by the weather channel into one system. with each graphics package, and graphical improvement included.
There would be two available options: the rack mount version and the desk version, the desk version would be the same as the rack mount version but wihtout the rack mount.
The minimum required to use the PCStar would be a monitor and keyboard. maybe a mouse...
Included on software would be stuff for scheduling and getting data to the main software.
